# Car Rental



## UI

## Backend
- Java 25
- Maven, or the included Maven Wrapper
```bash
cd backend 
mvn spring-boot:run or .\mvnw.cmd spring-boot:run
```
- http://localhost:8080

## Frontend
```bash
cd frontend
npm install
npm run dev
```
- http://localhost:5173
